# UIDAI Biometric Trend Analysis

## Overview
This project analyzes anonymised Aadhaar biometric enrolment and update data to identify time-based trends and operational insights.

## Problem Statement
Unlocking societal trends in Aadhaar enrolment and updates to support informed decision-making and system improvements.

## Dataset
- Anonymised biometric datasets provided by UIDAI
- Coverage: March 2025 – December 2025
- Multiple large CSV files consolidated programmatically

## Methodology
- Python (Pandas) used for large-scale data processing
- Monthly aggregation of biometric activity
- Visualization using Matplotlib

## Key Findings
- Biometric activity shows clear monthly variability
- Peak demand observed in mid-2025
- Significant anomaly detected in October 2025
- Recovery trend towards year-end

## Impact
The analysis highlights the importance of trend-aware and anomaly-aware operational planning for Aadhaar services.

## Tools Used
- Python
- Pandas
- Matplotlib

## Output
- Monthly trend visualization of biometric activity
